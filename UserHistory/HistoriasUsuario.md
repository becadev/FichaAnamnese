## Histórias de usuários
> Histórias de usuários base para nortear a criação da aplicação

1. Como estetiscista, quero criar um formulário base para dados gerais do cliente (nome, sobrenome, telefone, email, idade)
2. Como estetiscista, quero pode criar os formulários e vinculá-los a serviços para poder reutilizar
3. Como cliente, quero receber o formulário e responder online
4. Como estetiscista, quero poder anexar fotos no formulário do cliente
5. Como estetiscista, quero poder visualizar os formulários por status.
